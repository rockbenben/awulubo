# 五册整体视觉优化

日期：2026-11-16。作者授权五册整体优化构图、角色动作和字画关系，保持现有故事与文字不变。设计契约为主规格§0.13及五册冻结R7；本轮不提交、不发布。

## 画面改动

五册各28跨、合计140跨正文直接编辑在原书稿中。每跨有明确的取景与文字排布，前后置内容保留；不引入册专属运行时或构建入口。普通段落减少斜色带，保留已有色场；取景变化承担接近、观察、等待与沉降，背景不代替角色动作。

| 册 | 构图与动作重点 |
|---|---|
| 啊呜噜啵 | 吞食近景、鼓腹的重量、形体回落、偏头认识对方与挺腹回赠；数数、躲藏及彩纸来源保持。 |
| 噜啵生病啦 | 蜷缩、低身陪伴、嘴与杯子的距离、恢复时向前探身；毯边与眼睛、成人持药及末尾照顾孩子保持。 |
| 一起玩 | 护球与侧移、背身收拢、低身听候到转身回应；远景的等待与近景的争抢形成对比，同球与五路传球保留。 |

| 我自己来 | 身体与篮口同框保留动作因果，坐下、探看、让位及回应改变观看距离；三物的收纳次序、悬脚未碰与听停退开保持。 |

角色增加三种可复用受力轮廓及六种组合姿态，脚支点与身体偏转分开；仍是无手、双眼、有嘴及螺旋腹纹的原创角色。新增零件使用`g`与内联样式；嘴、腹纹、衣物保持组合锚点。未复制参考书的单眼、王冠、咒语或页面构图。

文字仅改变字号、位置、宽度及对齐：短句适当放大，观察句与角色拉开，部分动作先出现、旁白在下方承接；提示仍一行。第四册红色高潮页的原白纸垫随新文字位置调整，重新量墨迹对比度。

## 共用取景与回归

`framing`只改变观看距离；角色、道具的故事坐标、对象ID、动作参数与入篮归属不改。前景、热区及数字共同变换；文字独立排布，普通背景笔触不随镜头漂移。跨页场景按书脊补偿并在最终页框裁切。

原`verify-character`增加纸屏取景、墨迹／热区／数字同变换、文字独立、动画起点不变及实际错位反例；新姿态纳入原可见框、腹纹与穿戴像素回归。原`verify-scenes`增加远近取景与整幅场景参照、临时文件真实断景反例。两者继续由原`verify:teeth`入口在临时副本执行，不新增流水线。

第二册眼睛像素专项将取样带经过当前取景映射，保留原墨迹阈值和遮眼反例；不能把固定旧屏幕坐标当作新构图的眼睛位置。其余原有故事、生命周期、对象重排及物理关系断言保留。

数字重叠的破坏用例将第一枚数字的故事坐标映射到最终页坐标，再把第二枚数字叠到同处；原来的CSS反例在取景后没有实际重叠，必须修正反例的坐标而非放宽闸门。单独临时成品验证已确认纸屏两种版式均报告数字重叠，原失败退出码与错误断言保留。审稿快照从当前书稿重出，并补录取景；五份冻结R7及其指纹不改。

月亮上的白字低对比度反例也按同月亮的实际位置与取景定位，不继续依赖旧页坐标；白字尺寸随同缩放，原对比度阈值、报错与失败退出码保留。最后四组对比度、重复句、语言及授权破坏已先在隔离副本逐项验证通过，再执行完整入口。

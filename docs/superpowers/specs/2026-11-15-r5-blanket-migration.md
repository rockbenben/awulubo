# R5 第二册 p06–p07 毯角迁移记录

日期：2026-11-15。本阶段只迁移《噜啵生病啦！》S02，不改 R5 定稿读词，不进入其他跨页，不提交、不发布。

## 实施与根因

- p06 正文、纸屏提示及 aria 对齐 R5；保留杯子，移除药丸和星星，加入 `blanket-1` 毯角及唯一寻找热区。p07 同一毯子身份，紧邻以双脚揭晓，无额外提示或拟声大字；两页明确无进场拟声，点击仍保留确认音。
- 原 `find` 写死找到三个、按种类去重，并让所有找到的物件飞走。现在按本页 find 热区的 `targetId` 判断是否全部找到，同类不同身份分别计数；毯角原位保留，其他物件原有飞走反馈保留。继续通过 BookEffects 登记延迟完成，离页和重进取消旧回调，不直接翻页。
- 新增粉色折角组件；p07 复用原双脚组合成藏身姿态，去掉原先毯沿露出的身体和螺旋。仅此跨使用新组件；共享背景、入口、页序、loadBooks/loadSpecs、find 动作接口及原三物寻找保持兼容。
- 内容闸门原本也写死三目标、依赖种类和 class 推断寻找对象。find 分支改按真实对象身份和匹配类型验证；破坏回归改为缺失身份、重复身份必失败，不继续把合法单目标判错。其他动作检查保留。
- 字体子集与戳记、当前书稿快照和品牌产物按现有命令更新；专项接入 verify:teeth，交付须包含新增回归与此记录。

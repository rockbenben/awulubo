# R5 第二册 p12–p13 陪伴承诺迁移记录

日期：2026-11-15。仅处理 S05，不改 R5 定稿、不进入下一跨，不提交、不发布。

## 根因与实现

旧 p13 仍要求拿毯、点击盖毯，与已迁移的 p14 重复；旧 p12 也是暖和目标，未承载“我陪着你”的关系承诺。现将 p12 改为定稿“我陪着你。”及纸屏共用“坐近一点。”；p13 为“它往你身边靠了靠。”，不附加拟声大字、提示、盖毯对象或热区。两页 aria 同步，明确 noSound，移除旧进场拟声。

角色下一页从0.6放大到0.72并移近，新增 lean-close 组合姿态，将既有 tired 姿态与肚纹一起歪靠12度，保留疲倦神态，不增加康复承诺或新零件。页序、文件名、共享黄色背景保留；p14–p15 的内容和 cover 接口不改。

R5将“坐近一点”界定为模拟动作／共读邀请，不是拍打。渲染器原先把所有有角色的页自动标记 data-pat，不能表达安静阅读；增加可选 pat:false 并由渲染器遵守，只在本跨关闭默认拍角色反馈。未设置的页保持原有行为，普通点按、方向键与跨页规则不变，不新建动作名或强制任务。

更新 smoke 的第二册盖毯语义断言到 p14→p15，避免保留已废止的 p13 绑定。新增 verify-r5-care 并接入统一破坏回归。更新字体子集、戳记与当前书稿快照，品牌生成按项目约定执行。

## 可复现回归与画面

新专项首先在旧版本失败：p12–p15 同时有 p13、p14 两个盖毯动作；p13 仍有热区，纸书共读不是定稿。迁移文字后，又稳定发现 pat:false 未被渲染器遵守、两页仍生成 data-pat=1；修正后通过。

覆盖定稿读词、纸书覆写与 aria、移近及组合姿态、无旧盖毯／拍打、900px／1440px 普通阅读、方向键、点击角色作为普通翻页、未输入不自动跳页、重进及静态入口。测试等待既有翻页输入锁释放，不把锁内重复输入误判为翻页故障。

已查看p13成品：角色移近、放大且歪靠，身体和脚未裁切；无毯子。纸屏六处文字对比度通过：p12正文15.09:1、提示16.48:1，p13正文13.35:1。

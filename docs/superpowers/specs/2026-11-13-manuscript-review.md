## 如何使用这轮审稿

先连续读一册的旁白、大字和提示，检查故事是否成立；再回看每个跨页的画面与动作。重复的判断要看情节有没有推进：喂苹果、鱼、星星的重复有递进；“它在等”“它不伸手”“它也在等”若没有新的选择或后果，就可能只是在延长时间。

下面分两种证据：“现稿可确认”指文字、道具或热区声明已经显示出缺口；“编辑判断”指需要朗读、粗分镜或儿童试读进一步判断的节奏问题。本轮没有实际操作阅读器或逐页看校样，不据此认定可见框、动画或对比度合格，也没有儿童试读结论。

## P2 同步记录

当前逐跨数据区已改为由 `node tools/manuscript.mjs` 从工作区生成，含七条数字的值、位置与初始显隐；正文、纸书覆写、朗读稿、道具与热区身份均随源稿刷新。成人提示归入各册元数据，界面与字体工具共用文字源。第二册 p06 已改为寻找画面中的杯子、星星、药丸；第三册 p36 已补绑定球的上抛位移。下文保留原审稿时的编辑判断和检查记录，其他故事连续性、节奏与真人试读事项仍待处理。

## 第一册《啊呜噜啵！》

**成立的部分。** p08–p21 的喂食链有清楚的动作递进：单色→彩虹→吃撑→揉肚→喷彩纸。p46–p47 的赠礼也有关系上的回报：前面是孩子给它，后面是它给孩子。这两段值得保留。

| 页段 | 发现与依据 | 建议 |
|---|---|---|
| p24–p29 | **编辑判断：中场结束感较强。** “玩累了”“明天，再变新的颜色”“晚安”“第二天”构成一个完整小结。紧接着又开始找、藏、数、喊，整册可能被读成两个连续的小故事。 | 可以保留两天结构，但应明确第二天为何值得继续读，例如让第二天的游戏逐步指向最后的赠礼；先用朗读检验接力是否自然。 |
| p28 | **现稿可确认：主线中途有返回开头的出口。** 提示“摸摸噜啵，从头来。”，动作 `yawn` 声明 `exit: p04`。正文继续到 p59，但跟着角色动作走会先回到开头。 | 评估是否把重读集中到 p62。若保留中途出口，应在粗分镜与阅读路径中明确它是可选回环，并验证孩子能否发现继续读的路径。 |
| p42–p45 | **现稿可确认：叫它后的明确回应到 p44 才出现。** p42 已要求喊三声，p43 仍问“它听见了吗？”，p44 才是“它看见你啦！”。 | 把可辨认的回应放在 p43；p44–p45 再完成出现、靠近等升级。回声是同页反馈，不能独自替代故事里“它回应了你”。 |
| p46–p53 | **编辑判断：赠礼高潮后仍有三个较强动作。** 拍手、转圈、跺脚一直到 p53 才结束，p54 开始沉静。 | 不必删去一起玩，但用粗分镜确认三次动作逐渐收小，尤其不能让跺脚在声音和画面上超过赠礼高潮。 |

## 第二册《噜啵生病啦！》

**成立的部分。** 照顾与守夜构成区别于第一册的故事。p19 喂药、p20 吃下、p21 皱脸、p22 安慰，难受后有明确出口；p26–p35 的等待也有陪伴的内容，不应仅为了增加点击而缩短。

| 页段 | 发现与依据 | 建议 |
|---|---|---|
| p06–p07 | **现稿可确认：寻找的文字、对象和揭晓不对应。** p06 说“桌子底下没有。床底下呢？”，道具却只有杯子、药丸、星星，三个寻找热区也是这些对象；p07 才揭晓毯子底下的噜啵。 | 先决定孩子究竟在哪里找。若找毯子，就让前页的物件、提示和揭晓连成一件事；若找桌床，就必须画出这些家具并给出对应动作。 |
| p30–p35 | **编辑判断：等待段后半需要新的观察。** 颜色回来一点后，接连是还在睡、没反应、嘴边放苹果、仍没醒。 | 保留等待的长度时，让每跨出现一种细小但可辨认的变化，避免只是反复说“再等等”。具体变化在修订分镜中确定。 |
| p40–p49 | **编辑判断：恢复的确认过密。** 站起、转圈、跳、颜色回来、跟上、跑得飞快、变红、再说好了，共五跨。p45 的“脚有点软”到 p47 的“一点事都没有了”也转得很快。 | 整理成逐步增加能力的链条，让每次恢复都有不同意义；第二高潮之后避免再用一次强变色重新宣布康复。 |
| p61 | **现稿可确认：成人页仍比较屏幕与纸书。** 结尾写“纸书版没有声音；屏幕版可以点、可以听。”，而契约要求这一页只讲纸书共读。 | 用本册的纸书共读建议替换这句；其他册同类文字一起核对。 |

## 第三册《一起玩！》

**成立的部分。** 邀请被拒绝，等待也无效，最后真的争了一场；孩子仍愿意转回来再问一次，噜啵才答应。这比直接告诉孩子“要分享”更有故事性。p34–p35 第一次把球让给孩子，是这一册的关键转折。

| 页段 | 发现与依据 | 建议 |
|---|---|---|
| p36–p37 | **现稿可确认：屏幕动作承诺缺少对应热区。** p36 提示“点一下，一起扔。”，纸书覆写是“用力扔。”，但本页没有声明热区；p37 用静态位置表达球飞高。 | 若保留屏幕点按承诺，安排与球相关的抛起动作及下一页结果；若只做共读动作，就改成孩子实际能执行、且不暗示屏幕回应的提示。 |
| p38–p45 | **现稿可确认：持球者有未交代的切换。** p38 你递球、p39 轮到它、p40 它接住；p42 却直接变成“你再扔一次”。p43 它又接住，p44 又直接“球在你手里”。 | 逐页标明“谁持球→传给谁→谁接住”。补足必要的回传，或调整现有跨页承担的动作，使每次交接都看得懂；不增加页数。 |
| p38–p47 | **编辑判断：答应一起玩后，轮流动作略散。** 多次传、扔、接的变化主要是重述开心，第二高潮要靠球确实在两人之间来成立。 | 将这一段组织为第一次让出、第一次接回、双方自愿继续三步，保留快乐的重复，但每步都推进关系。 |

## 第四册《生气啦！》

**成立的部分。** 生气有倒塔这个具体起因，噜啵与孩子互相映照。p34–p35 再次倒下后还能“再搭”，能够用事件表现情绪变化；结尾留下未完成的塔，也容得下明天继续。

| 页段 | 发现与依据 | 建议 |
|---|---|---|
| p28–p45 | **编辑判断：行动和开口的转折先后不够有力。** p30 已“一起捡”，p32 已“再摞一次”，p35 又“倒了。再搭。”；到 p44–p45 才将“它先开口了／我们再搭一次”作为关键邀请。 | 两种可行方向：把邀请提前，让它启动重搭；或保留现有顺序，让后面的开口带来新的关系变化。修订时选定一条，避免再次发出已经执行过的邀请。 |
| p10–p11、p38–p43 | **编辑判断：情绪措辞需再审。** “跺也没用”可能使真实的情绪表达显得被否定；“气都拍出来了”又将情绪归结为动作排出。 | 保留跺脚与拍手的共读动作，用可观察的变化讲故事，例如身体慢了、手放松了；避免把某种表达直接判为无用。这里需要试读，不能仅凭审稿断定孩子的感受。 |
| p24–p43 | **编辑判断：缓和过程有两轮相似收束。** 第一次呼吸后脸已松开，重搭后又拍手、慢下来、再呼吸，最后还说生气会过去。 | 第一轮承担从僵住到能重搭，第二轮若保留，应体现再次遇到挫折时的选择；用同样动作表达“这次不同”，而不是重复宣布平静。 |
| p46–p47 | **编辑判断：叙述结论强于事件。** “生气会过去的”由旁白直接总结，后面配亮起和彩虹。 | 保留契约要求的主题时，让前面的重搭与主动开口先把意思演出来，再判断这里需要多少总结和视觉强调。 |

## 第五册《我自己来！》

**成立的部分。** p22 不责备、p23 蹲下、p25 拥抱，给失败留出被陪伴的空间。后半让噜啵等待孩子，是有价值的角色互换，应成为整册的中心。

| 页段 | 发现与依据 | 建议 |
|---|---|---|
| p06–p21 | **现稿可确认：失败链的主动作中断。** 先拿星星、吃苹果、倒水，p14 三样已经摔在地上；p16–p19 坐下、等待，p20 又“全洒了”，没有交代这次是在拿、倒还是搬什么。 | 先选择一件能贯穿失败与成功的具体事。若以收纳为主，就让失手与后来放进篮子形成因果；星星、苹果、倒水是否保留，要服从这条主线。 |
| p26–p33 | **现稿可确认：是谁在捡、重试了什么不够清楚。** “一个一个捡”“再捡小鱼”“放进篮子”没有明确主语；p30 说再试一次，成功的却是放苹果，不是前段的拿星星或倒水。 | 在关系转折处明确“它自己”或“你帮它”。让再次尝试完成前面未完成的同一件事，成功才有可理解的重量。 |
| p29–p45 | **现稿可确认：物品状态的交代有歧义。** p29 的三样物件已经按篮内位置摆放，p30 又捡起苹果；p36–p37 写“一个一个捡”“你伸手拿苹果”“再拿小鱼”，p42 仍说“三个都在地上”。源码注释说明 p37 还在犹豫，但可见文字没有明确表达这一点。 | 给同一批三样东西做逐跨状态记录：地面／伸手但未拿起／拿起／篮内。若前后是不同批次，要在故事与画面中明确；不能靠删掉“地上空了”一句来解决画面连续性。 |
| p34–p43 | **编辑判断：角色互换铺陈较长。** 轮到你、你蹲下、它看着、它不伸手、准备三样，占五跨后才实际收纳。 | 用更少的重复说明，把空间留给“它本来想帮，最后忍住，等你完成”这个可见的选择。具体跨页分配在完整修订稿中安排。 |
| p28、p34 | **现稿可确认：通用回应不能兑现主动作。** 两页都有 `poke`，只晃角色、发声，分别接在“放进篮子”“该你动手了”的文字旁；真正收纳在 p44。 | 决定哪些是它自己完成的叙事，哪些是孩子要做的互动。前者用画面交代，后者让孩子马上有相应对象和结果；避免点一下角色被理解为完成收纳。 |

## 五册连读时的共同问题

**每册的冲突已经不同，后半的解决与收尾仍较相似。** 第二册靠等待康复，第三册靠重新邀请，第四册靠一起承受挫折，第五册靠尊重自主；修订时应让这些解决方式各自站稳，避免都变成“几个小游戏→彩纸庆祝→睡觉”。相近的高潮位置是现有契约，不等于每册都要用同一种情节或同样的兴奋程度。

第三至第五册都从 p48 开始长段沉降，其中第四、第五册的躺下、晚安、呼噜、梦见物件、明天再玩尤其相似。沉静本身应保留；编辑上可以分别围绕“球留在两人中间”“塔没有搭完也可以睡”“收好后安心放手”形成不同余韵。是否缩短或改变分配，需要先修订设计契约，本轮没有调整固定的 64 页结构。

**提示槽中仍有许多故事句。** 例如第一册 p47“红的、蓝的、黄的……”、第四册 p48“塔还没搭完”、第五册 p13“到处都是水”。它们应先被当成故事内容审阅，再决定放旁白还是提示。不能为了让每页都有提示，强加一次通用点击。

**纸书成人页需要统一审阅。** 五册 p61 都保留“纸书版没有声音；屏幕版可以点、可以听”；部分册还用“点一下，它会……”描述反馈。应改成大人现场可做的共读行为。原朗读稿也有落后于可见文字的地方，例如第一册 p37 的 aria 仍讲藏在苹果后，而现旁白已经是跳出来；本次完整剧本特意将两者分列，修订时一起对齐。

## 下一轮创作顺序与交付标准

1. **先修故事。** 以第五册为先，明确一个贯穿的主动作、失败与重试、角色互换的时刻；再修第三册的球权链和第四册的转折位置。前两册分别解决回应距离、寻找对象与恢复段的节奏。
2. **再排 28 跨。** 每跨写一行“发生什么变化”，再写左右页文字。分清孩子做的动作和它自己做的事，结果紧邻兑现；不拿新增小游戏填充页数。
3. **朗读并做粗分镜。** 检查文字是否自然、画面能否承担没写出的交接、每次翻页是否有新信息，再画整册小样。中途停顿与结尾留白都需要通过实际阅读判断。
4. **定稿后正式制作。** 将选定方案更新到唯一设计契约，再同步书稿、画面与互动；涉及正文的改动先更新字体子集，再构建和完整验收。纯节奏讨论不直接驱动画面批量生成。

下一轮可交付的修订稿应能独立回答：这一册最想让孩子经历什么？它为什么在这里改变？孩子做完后下一页得到什么？高潮之后为什么还要继续这些跨页？读到最后，和开头的关系有什么不同？

## 本轮核对范围

- 逐册检查 64 页和 28 个正文跨页，使用共享装订分组；共 320 页、140 个正文跨页，屏幕合计 300 页。
- 提取后核对现稿全部可见文字槽、纸书覆写及 aria 均进入文档；每册保留源文件链接与来源 SHA-256。
- 运行现有的同页／邻页重复检查和跨页重复检查，结果只说明相应规则，没有替代上述人工编辑判断。实际运行结果见下方记录。
- 本轮只新增审阅文档；原故事、角色、画面、字体和阅读器均未因本轮审稿改动。实体打样、儿童试读、视觉节奏与动画效果仍待各自验证。

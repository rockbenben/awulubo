问题优先级只用来排工作，不给儿童打分：

- **立即暂停该候选**：错版／指纹不符、混入旧产物，或确定的关键因果、物品身份、纸型帖序、无法阅读／完成等缺陷。保存证据，不继续用同一错误样稿收集理解结论。
- **优先复核／修复**：独立会话同页反复混淆主动愿喝、谁接球、B3偏正、旁置块或停退；或成人可确认图文存在矛盾。先分清提示、疲劳与呈现因素，再确定根因，不直接改冻结词。
- **后续评估**：饰品重复感、幻想背景抢注意、沉降幅度等有具体证据但不妨碍主线的问题。可选喜好独立列出，不为热闹或单次偏好重写。

流程：登记原始事实 → 核对候选／提问／情境 → 成人复现或中性独立复核 → 分类并确定最小修复 → 在另一个内部候选修复 → 重出受影响产物并更新指纹 → 自动验收及人工同页、紧邻页和全链复测 → 复核人签名关闭。涉及共享组件须扩大到五册相同能力；涉及冻结读词或事件先提案、由作者确认新版本，不直接写R7。修复后不能只把旧行改成通过，必须保留旧证据与新增复测行。

## 表E：实体打样准备清单

以下是执行时待勾项目，本轮均未操作。

- [ ] 五册文件齐全，实际SHA-256与当前P3的artifacts.json匹配；不取历史专项PDF。
- [ ] 确认纸型、目标比例、打印设备、驱动、纸张克重／厚度及是否支持双面；登记操作者和任务号。
- [ ] 驱动设为**实际大小／100%**，关闭“适合可打印区域”、再次“小册子”、多合一和自动缩放；不得靠驱动补拼版。
- [ ] A4／A3用横向纸、双面翻转短边；先试印同册PDF第1、2面，折合核p64｜p01、p02｜p63是否正向，再印整册32面／16张纸。
- [ ] 打印机无法覆盖版面时先记裁切或缩放限制，换设备／工艺，不以自动缩小掩盖。
- [ ] 正式裁净210mm的字号、拿握和跨页检查使用216mm单页PDF按100%制作、每边裁3mm的装订样；纸张须能容纳出血页，由打样方安排拼印／裁切，不由家用驱动再次自动小册子化。
- [ ] A4／A3按现有拼版折订，裁切工艺单独说明；不在缩入的原稿上再次机械裁3mm。只做A4样时，正式比例结论保留待验。
- [ ] 五册各一本可翻阅的装订样；留每册正反封面、书脊／中缝和关键页证据，记录哪一本、哪一任务。未装订散页不能完成拿握与帖序验收。

| 文件类型 | 纸型与版面预期 | 能支持的结论与限制 |
|---|---|---|
| 单页PDF | 每页216×216mm，含每边3mm出血；100%后裁净210×210mm | 正式比例字号／断行、裁切／拿握；仍须正确装订后核帖序和跨页 |
| A4拼版 | 297×210mm横向；两幅148.5×148.5mm书页画面，垂直留白约30.75mm／侧 | 家用缩小拼版、正反方向与折订；不能代替正式比例字号／拿握结论 |
| A3拼版 | 420×297mm横向；两幅210×210mm书页画面，垂直留白约43.5mm／侧 | 当前骑马钉版型验收；代码将216mm原稿整体缩入210mm单元，含缩入的出血，不等于单页100%裁净210mm；未经实测不作为正式比例替代 |

预期值来自当前导出工具和规格，不是新增成品版型。实际纸张及画面宽高均以毫米记录，注明量具精度；发现未解释的整体缩小、偏心、缺边或系统尺寸偏差先暂停此任务，排查驱动／纸型后重打。不自行把约4%的额外缩小当合格容差，也不为迁就设备改作品比例。

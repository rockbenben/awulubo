### 3.2 八条可复用规则

1. **白纸是舞台**：单页只做一件事，文字页留白 60–80%。
2. **线必须“不完美”**：粗黑马克笔、圆头、线头外露、闭合不严、偶有重笔；无透视、无投影。
3. **颜色就是情绪**：黄=魔法/兴奋，红=危机/高潮，蓝=飞行/安静/夜，绿=自然，粉=甜/拥抱，紫黑=太空/黑暗。大面积平涂，允许涂出线外。
4. **字是画的一部分**：手写中文长在构图里；大动作词约 7–10% 页宽，正文 3.5–4.5%，括号小字 2.5–3%；波浪线、箭头、“错/对”示意。
5. **角色是符号**：参考书用单眼+王冠+豆形身体+火柴四肢，没有嘴；情绪靠瞳孔、睫毛、身体倾斜。眼睛还会藏在瓶罐里当“找一找”。
6. **互动是语法**：第二人称直接对话；指鼻子、闭眼、拍书、吹气、捂耳朵、转书、耳语；咒语故意念错→失败页；“按一下这个灰色方块”把页面变成按钮。
7. **节奏是"安静—爆发—安静"**：两个视觉高潮，**第一个约在 1/3、第二个约在 3/4**；结尾用蓝/红满版收；最后一页邀请重读。
   > 这里的"约 1/3 和 2/3"是早先看参考书的印象，**实测不是 2/3**：
   > 参考书 A 真正的爆发是 p49–p52 的烟花（全书 77–83% 处），p55 的满版红是情绪高潮；
   > 参考书 B 的两个高点在 p28–31 与 p56–59。第二个高点都落在 **3/4 前后**。
   > 量法见 `docs/reference/_analysis/rhythm.py`（满版色块占比）。
   > 那个指标是粗代理——参考书 p37–p38 的大片蓝天也被它判成"炸开"，

## 4. 概念与命名

### 4.1 一句话

一个圆滚滚、没有手的小怪物，吃什么就变什么颜色；吃太多会鼓成球，打嗝会喷彩纸；最后吃饱睡着。读者负责喂它。

### 4.2 名字系统

| 场景 | 用哪个 | 例子 |
|---|---|---|
| 书名/封面/扉页/结尾 | 全名 **啊呜噜啵** | 《啊呜噜啵！》 |
| 正文称呼 | 小名 **噜啵** | “噜啵，张嘴——” |
| 读者动作 | **啊呜** | “啊呜！” |
| 肚子饿 | **咕噜咕噜** | “咕噜——咕噜——” |
| 打嗝/彩纸 | **嗝——啵！！！** | 高潮页 |
| 睡觉 | **呼噜呼噜** | “呼噜……呼噜……” |

名字分工：**噜啵是名字，啊呜是动作，咕噜是肚子，嗝啵是结果，呼噜是结尾。** 孩子只要会叫“噜啵”，就能参与整本书。名字可以拍手念：**啊-呜-噜-啵**，四下拍手。

### 4.3 角色

- 圆身体，略不规则；肚子上一圈手绘螺旋（“噜”的视觉签名）。
- 大嘴（“啊呜”），最大张到 170°；没有手；两只小脚；可选一小段卷尾。
- 两只圆点眼 + 短眉毛；情绪靠嘴的角度、眼睛开合、身体倾斜。
- 颜色状态：白、红、蓝、黄、彩虹、淡（困）。
- 角色不能自己吃饭——这是读者必须参与的故事理由。

**行为谱系（它到底会做哪些事）**

到第十一轮之前，噜啵的本事只有五类：吃、变色、打嗝、累、藏。
而且它一直是**被动的**——孩子点它一下，它才动一下。现在分四族：

| 族 | 行为 | 页 |

第一册R7的关系转折在 **p42–p47**：p42 孩子呼喊，p43 角色当即答“我在这儿！”；p44–p45 从辨认声音推进到角色蹦到面前、挺起肚子；p46–p47 主动把肚子里的颜色送给孩子。早先接受喂食与身体回应，至此转为主动靠近和回赠，不再沿用旧 p45“我看见你啦”的逐字文案。

### 5.3.1 写给 3 岁的孩子：三条硬标准

上面那些是**排版**上的约束。这一节是**读者**上的：写完一段，问三个问题。

| 判据 | 问题 | 不合格的样子 | 合格的样子 |
|---|---|---|---|
| **能理解** | 三岁的孩子听得懂这个词吗？他认识这个东西吗？ | 「端一杯来」「再劝劝它」「睡得比昨天沉」「最难的一关」「像哄小孩子那样」 | 「拿杯水来」「再叫叫它」「睡得比昨天香」「喂它吃药」「轻轻地拍」 |
| **能接受** | 这一页会不会吓着孩子？生病、不吃药、皱脸——都要有出口 | 病得太惨、一直不好、没有任何好转的迹象 | 每一次难受都紧跟着一次照顾或好转；最难受的那页是**红**的爆发，下一页就是安慰 |
| **愿意互动** | 这一页有孩子能做的事吗？做完了有反应吗？ | 只有"翻页"这一件事，连续好几页 | 一页一件事：摸一摸 / 点一点 / 找一找 / 数一数 / 揉肚子——点下去有声音、有动作、有下一句 |

另有一条容易忽略的：**同一页里不要出现两遍同一句话。**
旁白与提示各说各的；提示是给孩子动手的那句（"用手指画圈。"），
旁白是念出来的那句（"转个圈，在噜啵的肚子上画圈。"）。
两页里也不要把同一句抄两遍（第一册 p18 与 p20 都写着"揉一揉，顺一顺"，
读起来像卡带了）。

还有一条：**同一页的图和字要对得上。**
第二册 p20 原来是一张笑脸配"怎么这张脸？"——孩子在问"脸怎么了"，
可画上根本没有异样。这一页的脸改成 `ouch`（眉头往里拧、眼睛挤起来），
问句才有着落。

还有一条 2026-11-04 才补上的：**一跨两页要读成"孩子做一个动作 → 翻页看见结果"。**
结果必须在**紧邻的下一页**，不能被推到两跨之外，也不能被别的情节插在中间。

| 毛病 | 例子 |
|---|---|
| 承诺被推到两跨之外 | 第一册 p05 提示"你喂我，好不好？"，可第一个苹果在 p08——中间隔着两页名字问答 |
| 提示承诺的动作，当页没有可点的 | 第一册 p43"再喊一声。"（上一页已喊满三声）、第三册 p46"举高高！"（整册没人兑现） |
| 提示提前剧透结果 | 第五册 p44"三样都收进篮子。"，可那是下一页 p45 才发生的事 |
| 道具与文字矛盾 | 第五册 p29"地上空了。"，可 p30 它又从地上捡起一个苹果 |
| 跨页自相矛盾 | 第三册 p48"球不滚了。"→ p49"球滚得慢了。" |
| 同一件事在相邻两页各说一遍 | 第五册 p20/p21"全洒了！"/"全洒了一地。" |

⚠️ **对仗不算重复**：「它看见你啦！」×「我看见你啦！」、
「你抓住球。」×「它也抓住球。」是两个孩子各说一句，剥掉主语后核心相同——
这是刻意的呼应，不是卡带，不要为了刷绿把它改成同一句。

⚠️ **动作页要交代结果**：第二册 p13 点毯子盖上，p14 直接跳到"要喝水"——
动作没有落点。中间必须有一句"毯子盖好了。"

### 6.5 角色板

- SVG viewBox：1000 × 1000。
- 身体直径 560；线宽 26（角色占 60% 页高时约 3 mm；小姿态加粗到 30–34）。

- **21 个姿态**：`idle`、`hungry`、`chomp`、`happy`、`peek`、`full`、`burp`、

> 角色读起来像一张贴图反复贴。64 页有 28 个跨页，同一个表情撑不住——
> 于是把情绪拆开：好奇、害羞、惊喜、调皮、欢呼、招手、困了、累了、得意、打哈欠；
> 第二册再加两个：`ouch`（难受）与 `grumpy`（不高兴、把脸转开）。
>
> 上述旧姿态列表保留接口历史，不规定R7逐页使用何种姿态。此前加手的制作方案已废止：孩子可以拍手，角色以小脚、圆身及表情回应，不能因旧cheer／wave命名再画出手臂。P1-1补充的13种组合及穿戴能力见阶段记录，后续按状态清单整册选用。
>
> 零件都在 `src/components/character.svg`，姿态是零件的组合——
> 加一种情绪只要写一个 `<g id="pose-xxx">`，不用重画角色。

### 6.7 页面节奏

> 下列色板序列与尺寸百分比为既有制作记录，尚未按 R5 迁移，不代表本次完成分镜或画面。R7的动作、场景及明确色变要求依§0.3冻结附件，仍遵守一跨一色系、变色须有正文、最后两跨最暗最静；不能机械沿用旧数值代替新的叙事事件。

- 色彩脚本（28 个跨页，按每跨页两页的底色场排；斜杠 = 同一跨页里底色变了）：
  黄/粉 → 绿/黄 → 蓝/红 → 绿/蓝 → 紫/黄 → 粉/米 → 橙/粉 → **米** →
  绿/黄 → **彩纸** → 黄/粉 → **夜** → 黄/绿 → 蓝/黄 → 米/黄 →
  **紫** → **紫** → **黄** → **黄** → 绿 → **黄** → 米/黄 → 黄 →
  橙/米 → 橙/黄 → 紫/蓝 → **夜** → **夜**。
  > 这里的"白"是**淡色满版底色场**（见 §6.8）：纸上仍有颜色，只是压得很淡，
  > 读起来还是白纸，但色块不再有"浮在白纸上"的孤岛感。
  > 底色按**段落**走：一段一个颜色——躲猫猫整段是紫的（p34–37），
  > 数一数整段是黄的（p38–41），尾巴整段是夜的（p56–59）。
  > 换了底色＝换了故事的一段，孩子看颜色就知道"又讲了一段"。
- 两个高点：**S9 彩纸喷发**（p20–21，33%）和 **S22 颜色都送给你**（p46–47，74%）。
  位置照参考书实测的 1/3 与 3/4 排（§3.2 规则 7）——不是凭感觉排的。
  最低点：**S27–S28 的夜**（p56–59），最后两跨页一路安静下去。
  > 实测（`docs/reference/_analysis/rhythm.py`，满版色块占比）：
  > p44–47 那四页是全书最"炸"的（82.6%），p56–59 最安静（5.4%）。
- 角色尺寸弧：30%（S1）→ 34%（S2）→ 38–50%（S3–S4）→ 55%（S5）→ 60%（S6）
  → **82%**（S7–S8 鼓成球）→ 62%（S9）→ 46–60%（S10–S11）→ 56%（S12）
  → 74%（S13）→ 42%（S14 找一找）→ 58%（S15）→ 52%（S17 躲猫猫）
  → 34%（S18 数一数）→ 58%（S21–S23）→ 56%（S24–S25）→ 46–52%（S26–S28 收小）。
  > 弧线是"吃大了 → 玩累了 → 睡着了"，跟故事同一条线；
  > 44 页版只到 20%（找一找）就一路小下去，没有再长大过。
- 每页只留一个动作；翻页前给一句提示。

### 6.8 背景：满版底色场 + 笔触

**背景分两层，两层都由框架算，不逐页手调。**

1. **满版底色场**：一整块毛边色块铺满整页（含出血）。
   它的半径大于页面对角线的一半，所以"铺满"是**几何保证**，不是靠放大倍数凑的。
   色块因此**长在页面上**，不再是浮在白纸上的孤岛。
   每页在数据里声明 `bg.wash`（用哪个色板令牌）；没有背景的页（环衬、给大人的话）不铺。
2. **笔触**：放射线 / 角落爆闪 / 色带 / 漩涡 / 色盘 / 彩纸 / 彩虹条 / 星星。
   放大倍数由「焦点到页面最远角的距离 ÷ 特效半径」算出，笔触永远冲出画外；
   每种特效的圆心与半径来自 `src/components/effects.json`，与图形同源生成。

底色场用**淡色**（`--wash-*`）：黑字对比度够（正文 ≥ 4.5:1），笔触才跳得出来；
高潮页（红 / 蓝 / 黄 / 彩虹 / 夜）用满色，此时笔触与底色同族，靠飞白分出层次。

> 旧做法只按"圆盘"假设放大笔触，可漩涡是环、彩纸是散点、角落爆闪从页外冲进来——
> 按圆盘算，16 页的背景都浮在白纸上。这条已由 §6.8 的两层结构取代。

### 7.3 页面契约

每个页面是一个 `<section class="page">` 片段，构建时拼进外壳：

```html
<section class="page t-food" data-id="p08" data-sound="chomp"
         aria-label="先吃一个红苹果。噜啵，张嘴——啊呜！">
  <div class="art" aria-hidden="true">
    <svg viewBox="0 0 1000 1000">
      <use href="#apple"/>
      <use href="#pose-hungry" class="char state-paper"/>
    </svg>
  </div>
  <p class="narration">先吃一个红苹果。</p>
  <h1 class="sound">啊呜</h1>
  <p class="prompt">点一下苹果，喂给噜啵。</p>
  <button class="hotspot" data-action="feed" data-target="apple"
          aria-label="喂噜啵吃红苹果"></button>
</section>
```

规则：

- 每页恰好一个 `<h1 class="sound">`，或 `data-no-sound`。
- 旁白/提示各 0–1 个；文字是真实 HTML，不烘进 SVG。
- 互动页至少一个 `.hotspot`，带 `aria-label`。
- 页面 ID 唯一；所有 `<use href>` 必须能在共享 defs 里找到。
- 文字必须在安全区内；构建时用 Playwright 量 `getBoundingClientRect()`。
- 页面内不允许外链、内联脚本、`onclick`。

### 7.4 角色组件

- `character.svg` 定义零件与姿态；姿态由零件组合，不重复画。
- CSS 变量控制颜色：`--body`、`--spiral`、`--cheek`、`--mouth`、`--tongue`。
- `.state-red { --body: var(--red); --spiral: #B31F1F; }` 等。
- `.state-rainbow` 用 `clipPath` + 6 条波浪条纹。
- 屏幕动画只动外层 `<g>`：`transform-box: fill-box; transform-origin: 50% 100%`；印刷不加动画类。
- 禁止在角色线条上用 `filter`；线宽、抖动全靠路径。

### 7.5 页面状态机

- `book.js` 读取 `pages`，当前页来自 `location.hash`（`#p04`），默认 p1。
- `goTo(i, direction)`：切换 `.is-active`，更新 hash，移动焦点，写 live region。
- 输入：点击/轻触（除 hotspot/按钮外）→ 下一页；左滑/右滑；方向键；空格/回车；Home/End。
- 翻页锁 350 ms，防止连点跳页。
- 最后一页是 p62（再读一次）；p63 后环衬、p64 封底只印刷。
- p62 显示“再读一次”圆形箭头，点击回 p4（第 1 个故事跨页）。
- 屏幕流程跳过 p60（版权页）、p61（给大人的话）、p63（后环衬）、p64（封底）；屏幕共 60 页。印刷包含全部 64 页。

**选页器（屏幕版）**：右上角页码按钮，点了铺开全部 60 页的缩略图，点哪张跳哪张。

- 缩略图是**页面画面层 SVG 的克隆**，不是位图——SVG 有 viewBox，缩到指甲盖大小也不糊
- 格子**懒建**：60 页的 SVG 全克隆出来有几千个节点，第一次打开时才建，之后复用
- 编号用**屏幕版序号**（1…60），不用印刷页码：按印刷页码编号会缺 4、61、63、64，看着像坏了
- 跳页**不经过 350 ms 的翻页节流**：那节流是防「一帧里跳两页」的，
  而选页是读者明确指定的一个目标，不是连点
- 64 页的书只能顺序翻的话，想找「数一数」那页要从头翻十几下——这不是小事

**全屏与防误触（屏幕版）**：左上角「全屏」按钮或 F 请求整个文档全屏，按钮随后显示「退出」；再次操作或 Esc 可退出。以浏览器的全屏状态事件同步按钮，不支持或请求失败时显示中文提示，继续普通阅读；旧 WebKit 以回调事件确认完成，等待期间忽略重复请求，错误或五秒未确认后恢复按钮。全屏操作不翻页，浮层打开时不响应 F；印刷、校样与拼版不启用。阅读区域及留白使用 `touch-action: manipulation` 避免连续轻点触发双击缩放，保留双指缩放；书页与工具按钮禁止选字和长按菜单，书页禁止拖拽，揉肚子的热区仍独占画圈手势。工具按钮上起始的滑动不翻页，滑动绑定本次进入的书页，离页重返后旧滑动无效；双指操作不当作翻页，放大后单指拖动画面，缩回原大小后恢复滑动翻页。工具按钮保持 44px 触摸尺寸并避开刘海安全区。全屏不保证锁住系统手势或阻止切换应用。

### 7.5.1 一册 = 一本书

**册的划分**

| | |
|---|---|
| 一册 | 一本书 = 64 页（3 前置 + 56 故事 + 5 后置）——版权页在书末，正文从 p4 起，见下 |
| 册的清单 | `src/content/books/index.js`——浏览器端拿不到文件系统，册的列表必须显式写出来 |
| 每册的内容 | `src/content/books/<册 id>/`：`book.json`（书名、副标题）+ `specs/*.js`（页面数据） |
| 加一册 | 建目录 + 在清单里加一行。构建、检查、字体子集、截图都跟着走，不用改代码 |

**页码在册内独立**——每册都从 `p01` 开始。所以：

- 地址栏用 `?book=<册 id>#p30`：册在 query、页在 hash，两个都能分享
- 别的册的页面带 `is-off-book`，不显示——打印/拼版模式下页面是平铺的，
  不藏就会把几册拼在一起印；骑马钉的帖序也在册内各算各的
- 选页器的编号用**屏幕版序号**（1…60），不按印刷页码——按印刷页码会缺 60、61、63、64，看着像坏了

**模式**

| 模式 | 是什么 |
|---|---|
| 网页 | 默认。会叫会回应；屏幕够宽时摊开成**跨页**（`index.html`） |
| 打印版 | 整册 64 页摊平，送印厂（`print.html`） |
| 骑马钉拼版 | A4 双面拼版，对折即成书（`booklet.html`） |

**网页版的跨页**

网页版是**翻书**，不是一页一页放幻灯片。屏幕够宽（≥1100px）时摊开成两页：
左右并排，中间一道书脊的阴影，翻一次翻一跨。

| | |
|---|---|
| 哪两页对在一起 | **由装订决定**：骑马钉的书永远翻到「偶数页 \| 奇数页」——封面 p1 单页，往后 (p2\|p3)、(p4\|p5)…… 屏幕版跳过的那几页不在跨页里，搭档独自成页（封面、故事第一页、再读一次那页） |
| 为什么不能自己配 | 纸书翻开来是哪两页，网页就得是哪两页：同一段故事，屏幕上一屏两页、纸上一翻两页，孩子看到的才是一样的翻法。网页另配一套，纸和屏就成了两个故事 |
| 断点 | 1100px。每页只占一半屏宽，字就小一半：1100px 时每页 550px，正文 3.4% 的字高约 19px；再窄就一页一屏（手机上两页字太小） |
| 谁来实现 | 分组在 `book.js` 的 `buildSpreads`，摆开在 `book.css` 的 `@media (min-width: 1100px)`。⚠️ **断点写了两遍**（CSS 与 JS 的 `SPREAD_QUERY`），不一致时屏幕摊着两页、翻页却只走一页 |
| 点哪一边 | 点**右页**往前、点**左页**往回——摊开时左边是刚读过的那页，右边是还没读的那页，跟翻纸书一样。点在书页之外（上下留白、舞台两侧）仍算往前，那是「继续」的意思 |
| 页码显示 | 跨页时显示范围（「8–9/60」），不是单页号 |
| 互动 | 两页各有各的热区；多步互动的页（`trap`）按**整组**算——点另一页的空白也不能翻过去 |
| 底色 | **一跨一个色系**：同一跨的左右两页共用一套底色场（同样的 `colors` / `gap` / `wash`），放射线、漩涡的圆心对着书脊，左右各露一半，翻开来是**一幅画**。只有正文自己说了「变红啦」「颜色要回家了」这种转折，才允许这一跨换色——换色的那两页，右页是左页的结果 |

⚠️ **模式是链接，不是就地换 body 的 class。**
印刷版与屏幕版的**文案不同**（纸上点不动，"点一下，往后翻"要改成"翻过来找找看"，共 4 页有差别），
就地换 class 印出来的还是屏幕版的字。真正的印刷版是 `print.html`——
它是用印刷文案单独构建的那一份（`vite-pages.mjs` 的 `scope`）。

外壳（`shell.js`）在屏幕版的右上角：**选一册** + **看它的方式**。

### 7.7 音频

- Web Audio API 合成，无音频文件。
- 首次点封面时解锁 `AudioContext`；封面就是“开始”按钮。
- 音色：
  - `gulu`：90 Hz 正弦 + 6 Hz 颤音，0.6 s。
  - `chomp`：0.06 s 噪声 + 120→80 Hz 正弦，0.15 s。
  - `burp`：110→70 Hz 锯齿 + 500→150 Hz 短滑音（“啵”），0.45 s。
  - `snore`：低通噪声 + 60 Hz 正弦，1.8 s。
  - `pop`：600→200 Hz 正弦，0.1 s。
- 主音量 0.25；静音按钮 + `M` 键；不持久化。
- `prefers-reduced-motion` 不影响声音；静音是独立开关。

### 7.8 彩纸

- 每个爆发页由构建脚本用固定种子生成 96 个形状（圆/方/星/波浪/花），颜色从色板取。
- 形状的最终位置在构建时写死；屏幕动画从嘴巴位置飞到最终位置，1.2 s。
- 印刷时关闭动画，保留最终构图；屏幕/印刷共用同一批形状。
- `prefers-reduced-motion` 时直接显示最终构图。
- 不用 canvas；SVG + CSS transform，便于截图和印刷。

### 7.9 无障碍

- 每页 `aria-label` 是完整朗读文本；画面 `aria-hidden`。
- 页面切换后焦点移到页面容器；隐藏的 live region 播报当前页文字。
- 键盘：←/→、空格、回车、Home/End、M 静音、F 全屏、? 帮助。
- `prefers-reduced-motion`：翻页瞬时、彩纸不动、螺旋不转。
- 对比度：正文 ≥ 4.5:1；大字 ≥ 3:1；黄底用黑字。
- 不闪烁；无自动播放声音；封面点击后才发声。
- PDF 设置 `lang="zh-CN"`、`tagged: true`。

### 7.10 屏幕布局

- `body` 白底；`.stage` 居中，`width/height: var(--page)`。
- 页面绝对定位叠放；只显示 `.is-active`；`overflow: hidden`。
- 无滚动条；手机竖屏上下留白，舞台仍然 1:1。
- 字号/间距全部基于 `--u`，随舞台缩放。
- 只有两个常驻 UI：右上角静音按钮、帮助按钮；3 秒后淡出，点击页面再出现。印刷时隐藏。
- 构建产物是单个 `index.html`；桌面双击可读。iPad 建议用本地静态服务器或私有站点，避免 `file://` 的音频/字体限制。

### 8.1 规格

| 项 | 值 |
|---|---|
| PDF 页面 | 216 × 216 mm |
| 成品 | 210 × 210 mm |
| 出血 | 3 mm 四边 |
| 安全区 | 成品内缩 8 mm |

| 订口 | 折线在奇数页左边、偶数页右边；内容安全区内缩 8 mm，跨过折线的笔触允许 |
| 色彩 | sRGB PDF；印厂转 CMYK，必须打样 |

### 8.2 导出流程

1. `npm run build` 生成 `dist/print.html` 与 `dist/booklet.html`。
2. `node tools/pdf.mjs` 与 `node tools/pdf-booklet.mjs`：
   - Playwright Chromium 打开 `print.html` / `booklet.html`。
   - `await document.fonts.ready`；等待无网络请求。
   - 单页版导出 `dist-print/<册 id>.pdf`（216 × 216 mm 出血单页，64 页）。
   - 拼版导出 `dist-print/<册 id>-a4-duplex.pdf`（及可选 `--a3` 的 A3 版本）。
   - 脚本内嵌验证：页数 64（4 的倍数）、216 mm 方形尺寸、字体全部内嵌白名单（无未授权系统字体、无 Type3）。
3. 版式与出血检查：
   - `node tools/check-layout.mjs`：在 216 mm 宽度下量所有文字元素，必须在 11 mm 内边距内；文字容器无溢出；屏幕 UI 在 print 媒体下 `display: none`。
   - `npm run shots:print && python tools/check-shots.py`：逐页验证印刷版渲染、四角出血颜色与墨迹分布。
4. 人工检查 4 个关键页的 300 dpi 渲染：封面、红页、彩虹页、夜页。
5. 印厂打样；确认 CMYK 色偏、黑字是否够黑、线条是否够粗。

### 8.3 裁切线

- 默认交付 216 × 216 mm 出血 PDF；印厂按出血裁切。
- 如印厂要求裁切线，用 `pdf-lib` 生成 226 × 226 mm 版本，在成品框外画角线；不改变内文 PDF。

### 8.4 色彩

- 屏幕用 sRGB 色板；印刷前提供 `palette.csv`（RGB + CMYK 近似值）。
- 荧光黄/红在 CMYK 里会变暗；先打样，必要时把 `--yellow` 调到 `#FFD400`、`--red` 调到 `#E23B2E`。
- 封面可用 Pantone 803C（黄）/ 485C（红）提亮；内文用 CMYK。
- 黑色：文字 100K；线条可用 100K + 30C 富黑，需印厂确认。

### 13.1 名称与商标查重记录（2026-10-31）

按证据强度分三层。**只有第 3 层（中国官方库）能对"能不能用"下结论，前两层只能降低担忧。**

| 层 | 数据源 | 结果 | 能证明什么 / 不能证明什么 |
|---|---|---|---|
| 1. 网页 | 搜索引擎、书店目录、电商、应用商店 | 全网无同名绘本 / 品牌 / App / 游戏 | 没有「已经火到不用搜」级别的撞名；查不到 ≠ 不存在 |
| 2. 国际商标库 | WIPO Global Brand Database（85 个知识产权局、77,158,090 条，2026-10-30 数据） | 精确短语检索：**「啊呜噜啵」0 条、「噜啵」0 条、「啊呜」0 条、「AWULUBO」0 条**。对照组「LABUBU」319 条（泡泡玛特 class 28 等）→ 检索本身有效 | 欧美日韩印澳加英等 **85 个局**未被占用。**GBD 收录清单里没有 CNIPA，中国国内注册查不到，这层结论不覆盖中国** |
| 3. 中国官方库 | 商标网 `wcjs` / `pub` / `toas` / `tzwh` | 本机 IP `58.38.113.254`（阿里云机房段）被盾墙拦截，四个数据域全部 403，拦截页写明「抱歉，您的请求被阻断了 / Your IP 58.38.113.254」 | **无法从这里完成**。需在住宅网络人工查 9/16/28/41 类，或委托代理机构 |

另两条实打实的在先使用线索：

- **「啊呜」已经是出版书名**：《啊呜》（萧袤/唐筠，浙江少年儿童出版社 2013，ISBN 9787534277894，44 页）；另有《啊呜一口，吃掉烦恼》（人民邮电出版社 2023）、《啊呜啊呜大面包》（海洋出版社 2009）。书名不是商标，但 16/41 类的在先使用证据是实的——正式查重时以「啊呜」二字单列查一遍。
- **「噜啵」与泡泡玛特 Labubu（拉布布）音近义同**（都是给孩子的小怪物）。LABUBU 在 GBD 有 319 条全球注册、泡泡玛特持 class 28。整书名「啊呜噜啵」四音节 vs la-bu-bu 三音节、字形全不同，**不构成近似**；形象也刻意避开（无尖耳、无尖牙，只有肚子上的螺旋）。风险点在于**若「噜啵」被单独当作商品名称/商标用在玩具上**，届时须另做判断。

**结论**：作为**整体**书名，「啊呜噜啵」在全球范围未见占用，可以用；中国国内能否注册**尚未知**，出版/上架前必须人工查一次商标网。备选「啊呜噜咕」保留在案。

|---|---|---|---|

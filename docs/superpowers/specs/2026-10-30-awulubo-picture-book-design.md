## 1. 目标与非目标

### 目标

1. 做一本 3 岁孩子能独立参与、大人愿意反复读的互动绘本。
2. 画面全部由 HTML / CSS / SVG 构成，不依赖位图插画。
3. 一套页面源码，同时产出：
   - 屏幕互动版：离线可用，点按驱动，有声音，支持减少动效。
   - 印刷 PDF：216 × 216 mm（含 3 mm 出血），矢量线条，字体嵌入。
4. 每一页在纸上都成立；互动只做庆祝性反馈，不做分支。
5. 画风承接参考书的“白纸 + 粗黑线 + 饱和纯色 + 手写字入画 + 第二人称指令”，角色、文本、桥段原创。

### 非目标

- 不做分支剧情、不做多结局。
- 不做麦克风、摄像头、体感、账号、后端、统计。
- 不做 App 商店打包、视频版、多语言版（首版只做简体中文）。
- 不做复杂 3D、渐变、写实光影。
- 不做逐帧动画；只做一个动作一个反馈。

## 2. 读者与阅读场景

- **核心读者**：3 岁，能说短句、能指认颜色、喜欢重复和拟声词。
- **共读者**：家长/老师，负责念旁白、做音效、引导孩子点按。
- **场景**：睡前、亲子共读、幼儿园小班。
- **单次阅读时长**：3–5 分钟。
- **文本规则**：
  - 每页旁白 ≤ 2 行，每行 ≤ 13 个汉字。
  - 每页只做一个动作（点、揉、说“啊呜”）。
  - 因果必须在一页内发生；翻页即结果。
  - 重复句：`咕噜——咕噜——`、`噜啵，张嘴——啊呜！`、`嗝——啵！！！`、`呼噜……呼噜……`。
  - 拟声词用大字，旁白用小字；旁白是给大人念的，拟声词是给孩子跟的。

## 3. 参考书分析：可复用的风格基因

### 3.1 两本书的硬信息

| | 《太神奇啦！》 | 《神奇的故事又来啦！》 |
|---|---|---|
| 页数 | 64 | 64 |
| 开本 | 550.8 × 580.8 pt ≈ 194 × 205 mm 近方形 | 扫描 A4，画面约 210 × 210 mm |
| 画面 | 纯白纸 + 马克笔平涂 + 密排手写字 | 水粉/丙烯质感 + 大场景 + 角色满页特写 |
| 结构 | 纸面魔术：变身→消失→形状→找眼睛→吹气飞行→烟花→睡觉→再见 | 场景冒险：魔法王国→消失→烟花→恶作剧→糖果→选颜色→彩纸 |
| 高潮 | 黄放射线、红放射线、彩色烟花 | 烟花、彩纸、颜色选择 |

### 3.2 八条可复用规则

1. **白纸是舞台**：单页只做一件事，文字页留白 60–80%。
2. **线必须“不完美”**：粗黑马克笔、圆头、线头外露、闭合不严、偶有重笔；无透视、无投影。
3. **颜色就是情绪**：黄=魔法/兴奋，红=危机/高潮，蓝=飞行/安静/夜，绿=自然，粉=甜/拥抱，紫黑=太空/黑暗。大面积平涂，允许涂出线外。
4. **字是画的一部分**：手写中文长在构图里；大动作词约 7–10% 页宽，正文 3.5–4.5%，括号小字 2.5–3%；波浪线、箭头、“错/对”示意。
5. **角色是符号**：参考书用单眼+王冠+豆形身体+火柴四肢，没有嘴；情绪靠瞳孔、睫毛、身体倾斜。眼睛还会藏在瓶罐里当“找一找”。
6. **互动是语法**：第二人称直接对话；指鼻子、闭眼、拍书、吹气、捂耳朵、转书、耳语；咒语故意念错→失败页；“按一下这个灰色方块”把页面变成按钮。
7. **节奏是“安静—爆发—安静”**：约 1/3 和 2/3 各一次视觉高潮；结尾用蓝/红满版收；最后一页邀请重读。
8. **幽默靠旁白**：括号吐槽、对读书的大人下手、“休息时间”整页涂鸦。

### 3.4 版权边界

## 4. 概念与命名

### 4.1 一句话

一个圆滚滚、没有手的小怪物，吃什么就变什么颜色；吃太多会鼓成球，打嗝会喷彩纸；最后吃饱睡着。读者负责喂它。

### 4.2 名字系统

| 场景 | 用哪个 | 例子 |
|---|---|---|
| 书名/封面/扉页/结尾 | 全名 **啊呜噜啵** | 《啊呜噜啵！》 |
| 正文称呼 | 小名 **噜啵** | “噜啵，张嘴——” |
| 读者动作 | **啊呜** | “啊呜！” |
| 肚子饿 | **咕噜咕噜** | “咕噜——咕噜——” |
| 打嗝/彩纸 | **嗝——啵！！！** | 高潮页 |
| 睡觉 | **呼噜呼噜** | “呼噜……呼噜……” |

名字分工：**噜啵是名字，啊呜是动作，咕噜是肚子，嗝啵是结果，呼噜是结尾。** 孩子只要会叫“噜啵”，就能参与整本书。名字可以拍手念：**啊-呜-噜-啵**，四下拍手。

### 4.3 角色

- 圆身体，略不规则；肚子上一圈手绘螺旋（“噜”的视觉签名）。
- 大嘴（“啊呜”），最大张到 170°；没有手；两只小脚；可选一小段卷尾。
- 两只圆点眼 + 短眉毛；情绪靠嘴的角度、眼睛开合、身体倾斜。
- 颜色状态：白、红、蓝、黄、彩虹、淡（困）。
- 角色不能自己吃饭——这是读者必须参与的故事理由。

### 4.4 与参考书的差异

- 有嘴、有螺旋肚子、没有手；不是单眼+王冠。
- 魔法是“吃东西变色”，不是咒语。
- 文本是原创的拟声词系统，不复制原书任何句子。
- 名字只借“拟声词 + 直接对话”的气质，不复制“杜噜嘟嘟”的字形或音节结构。

### 5.3 文字总量

- 拟声词 + 旁白 + 提示约 **600 字**（2026-10-30 实测 681 字，含版权页与"给大人的话"两页印刷专用文字；
  亲子共读时念给孩子听的是"旁白 + 拟声词"，约 450 字）。
  > 原稿写"200–250 字"，与本节 §5.2 自己的剧本对不上——按剧本逐页写出来就是这个量级，
  > 以剧本为准，这里改成实测值。逐页约束（旁白 ≤2 行、每行 ≤13 字）不变 ✓。
- 每页只出现一个核心动作词：`啊呜`、`嗝`、`呼噜`、`咕噜`。
- 不出现成语、比喻、复杂从句；不出现"因为/所以/但是"。
- 拟声词允许重复，旁白不重复。

### 5.4 循环与重读

- 第 11 跨页结尾问“今天，你喂噜啵吃什么？”，第 12 跨页是找一找。
- 第 13 跨页是躲猫猫（参考书的“咦？不见了”），第 14 跨页是数一数。
- 最后一页（p34）是一个手绘圆形箭头 + “再读一次”；点击回到第 1 跨页。
- 印刷版用“再读一次”文字 + 箭头，不需要按钮。

规则：

- 每页最多 3 个填充色 + 黑 + 白；彩虹/彩纸页除外。
- 黄底黑字；红/蓝底的大字用白；正文放在白色手绘底块上。
- 不用渐变、不用阴影、不用半透明叠色（纸纹除外）。
- 荧光黄/红超出 CMYK 色域；先打样，封面可考虑 Pantone 803C / 485C。

### 6.3 字体

| 用途 | 字体 | 授权 | 备选 |
|---|---|---|---|
| 拟声词/提示 | 站酷快乐体（ZCOOL KuaiLe） | **SIL OFL 1.1**（@fontsource / googlefonts 版本，已核验，可商用） | 悠哉字体（OFL） |
| 正文/旁白 | 霞鹜文楷（LXGW WenKai） | **SIL OFL 1.1**（已核验，可商用） | 系统楷体 |

- 字体子集化：`pyftsubset`，按全书实际文本生成 WOFF2。
- 构建检查：每个渲染字符必须在子集里，缺字即失败。
- 拟声词逐字 ±3° 旋转、±2% 位移；正文不抖。
- 数字/标点用同一字体，不混排。

### 6.4 字阶

| 用途 | 字号 | 行高 | 规则 |
|---|---|---|---|
| 拟声词 | 12–22 `--u`（26–48 mm） | 0.95 | 2 字 22u，4 字 14–16u；最多 2 行 |
| 旁白 | 3.4 `--u`（7.3 mm ≈ 20 pt） | 1.5 | 每页 ≤2 行，每行 ≤13 字 |
| 动作提示 | 4.0 `--u`（8.6 mm ≈ 24 pt） | 1.3 | 底部居中，一句话 |
| 大人旁白 | 2.2 `--u`（4.8 mm ≈ 13 pt） | 1.4 | 灰色 `#6B6B6B`，仅 p29 |

### 6.5 角色板

- SVG viewBox：1000 × 1000。
- 身体直径 560；线宽 26（角色占 60% 页高时约 3 mm；小姿态加粗到 30–34）。
- 5 条路径：身体轮廓、嘴、螺旋、眼睛、脚。
- 7 个姿态：`idle`、`hungry`、`chomp`、`full`、`burp`、`sleep`、`peek`。
- 6 个颜色状态：`state-paper`、`state-red`、`state-blue`、`state-yellow`、`state-rainbow`、`state-pale`。
- 线条是手绘路径，**不用 SVG filter**；线头略出头、闭合不严。
- 螺旋：屏幕慢转；印刷静态 + 两根小短线。
- 彩虹：6 条波浪条纹 `clipPath` 裁进身体。

| `t-rainbow` | 六条波浪条纹 | 角色居中；白色手绘底块放字 | S5 |
| `t-burst` | 满版彩纸 | 角色 50%；拟声词最大，放白色手绘底块 | S7–S8 |
| `t-night` | 深蓝/紫 | 月亮+星；角色躺下；小白字 | S10 |
| `t-search` | 白 | 散落道具；角色 20% 探头；底部“再读一次”箭头 | S12 |

阅读路径固定：左上旁白 → 角色/动作 → 底部动作提示。点按目标 ≥ 25% 页宽，屏幕 ≥ 120 × 120 CSS px。

### 6.7 页面节奏

- 色彩脚本：白 → 红 → 蓝 → 黄 → 彩虹 → 白 → 彩纸 → 彩纸 → 淡 → 夜 → 白 → 找一找。
  > 这里的"白"是**淡色满版底色场**（见 §6.8）：纸上仍有颜色，只是压得很淡，
  > 读起来还是白纸，但色块不再有"浮在白纸上"的孤岛感。
- 两个高点：彩虹（视觉）和彩纸（动感）；最低点：夜。
- 角色尺寸弧：30% → 55% → 65% → 80%（鼓成球）→ 70% → 50% → 35% → 20%（找一找）。
- 每页只留一个动作；翻页前给一句提示。

### 6.8 背景：满版底色场 + 笔触

**背景分两层，两层都由框架算，不逐页手调。**

1. **满版底色场**：一整块毛边色块铺满整页（含出血）。
   它的半径大于页面对角线的一半，所以"铺满"是**几何保证**，不是靠放大倍数凑的。
   色块因此**长在页面上**，不再是浮在白纸上的孤岛。
   每页在数据里声明 `bg.wash`（用哪个色板令牌）；没有背景的页（环衬、给大人的话）不铺。
2. **笔触**：放射线 / 角落爆闪 / 色带 / 漩涡 / 色盘 / 彩纸 / 彩虹条 / 星星。
   放大倍数由「焦点到页面最远角的距离 ÷ 特效半径」算出，笔触永远冲出画外；
   每种特效的圆心与半径来自 `src/components/effects.json`，与图形同源生成。

底色场用**淡色**（`--wash-*`）：黑字对比度够（正文 ≥ 4.5:1），笔触才跳得出来；
高潮页（红 / 蓝 / 黄 / 彩虹 / 夜）用满色，此时笔触与底色同族，靠飞白分出层次。

> 旧做法只按"圆盘"假设放大笔触，可漩涡是环、彩纸是散点、角落爆闪从页外冲进来——
> 按圆盘算，16 页的背景都浮在白纸上。这条已由 §6.8 的两层结构取代。

## 7. 技术架构

### 7.1 栈

- HTML5 + CSS 自定义属性 + 容器单位（用 `--u`，不用运行时测量）。
- 内联 SVG（`<symbol>` / `<use>`）；无位图插画。
- 原生 JavaScript，无框架、无 CDN；构建时按顺序拼成一个经典脚本，不用 ES modules。
- 构建时把 CSS、JS、SVG、字体子集全部内联进单个 `index.html`；桌面双击即可打开，不依赖服务器。
- Node 24 构建脚本。
- Playwright（Chromium）导出 PDF 与截图。
- Python 3.15（PyMuPDF、Pillow、fontTools）做 PDF/字体检查。

### 7.3 页面契约

每个页面是一个 `<section class="page">` 片段，构建时拼进外壳：

```html
<section class="page t-food" data-id="p07" data-sound="chomp"
         aria-label="先吃一个红苹果。噜啵，张嘴——啊呜！">
  <div class="art" aria-hidden="true">
    <svg viewBox="0 0 1000 1000">
      <use href="#apple"/>
      <use href="#pose-hungry" class="char state-paper"/>
    </svg>
  </div>
  <p class="narration">先吃一个红苹果。</p>
  <h1 class="sound">啊呜</h1>
  <p class="prompt">点一下苹果，喂给噜啵。</p>
  <button class="hotspot" data-action="feed" data-target="apple"
          aria-label="喂噜啵吃红苹果"></button>
</section>
```

规则：

- 每页恰好一个 `<h1 class="sound">`，或 `data-no-sound`。
- 旁白/提示各 0–1 个；文字是真实 HTML，不烘进 SVG。
- 互动页至少一个 `.hotspot`，带 `aria-label`。
- 页面 ID 唯一；所有 `<use href>` 必须能在共享 defs 里找到。
- 文字必须在安全区内；构建时用 Playwright 量 `getBoundingClientRect()`。
- 页面内不允许外链、内联脚本、`onclick`。

### 7.4 角色组件

- `character.svg` 定义零件与姿态；姿态由零件组合，不重复画。
- CSS 变量控制颜色：`--body`、`--spiral`、`--cheek`、`--mouth`、`--tongue`。
- `.state-red { --body: var(--red); --spiral: #B31F1F; }` 等。
- `.state-rainbow` 用 `clipPath` + 6 条波浪条纹。
- 屏幕动画只动外层 `<g>`：`transform-box: fill-box; transform-origin: 50% 100%`；印刷不加动画类。
- 禁止在角色线条上用 `filter`；线宽、抖动全靠路径。

### 7.5 页面状态机

- `book.js` 读取 `pages`，当前页来自 `location.hash`（`#p05`），默认 p1。
- `goTo(i, direction)`：切换 `.is-active`，更新 hash，移动焦点，写 live region。
- 输入：点击/轻触（除 hotspot/按钮外）→ 下一页；左滑/右滑；方向键；空格/回车；Home/End。
- 翻页锁 350 ms，防止连点跳页。
- 最后一页是 p30（再读一次）；p31 后环衬、p32 封底只印刷。
- p34 显示“再读一次”圆形箭头，点击回 p5（第 1 个故事跨页）。
- 屏幕流程跳过 p4（版权页）、p33（给大人的话）、p35（后环衬）、p36（封底）；屏幕共 32 页。印刷包含全部 36 页。

### 7.6 互动

| 动作 | 触发 | 反馈 | 之后 |
|---|---|---|---|
| 点肚子 | p5 螺旋 | 咕噜声 + 螺旋转一圈 | 翻页 |
| 点食物 | p7/p9/p11/p13 | 食物缩小飞进嘴 + 啊呜声 | 自动翻到颜色页 |
| 点三样 | p13 | 依次计数 1/2/3 + 音效 | 第三样后翻到彩虹页 |
| 点/戳肚子 | p16 | 身体晃 + 咕噜声 | 翻页 |
| 画圈揉肚子 | p17 | 螺旋跟着手指转 + 咕噜声 | 翻页到彩纸页 |
| 点彩纸 | p19 | 彩纸变成小花 + 啵声 | 翻页 |
| 点月亮 | p23 | 灯光变暗 + 呼噜声 | 翻页 |
| 点噜啵 | p25 | 打哈欠 + 咕噜声 | 回到第 1 跨页 |
| 找一找 | p27 | 点对发音/计数；点错轻微摇头 | 集齐 3 个后鼓励 |
| 拍一拍 | 任意有角色的页 | 噜啵晃一下 + 叫一声（点空白一样翻页） | 翻页 |
| 数一数 | p31 | 点一个苹果 → 旁边冒出 1、2、3 | 数满 3 个后翻页 |

- 所有 hotspot 都是真 `<button>`，最小 120 × 120 CSS px，`touch-action: manipulation`。
- 点中 hotspot 阻止冒泡，避免同时翻页。
- 效果 600–900 ms；期间再点任意处可跳过效果并翻页。
- 不做长按、复杂拖拽、吹气、麦克风；3 岁只需要点/揉。只保留一个“揉肚子”的圆周手势，并提供连点肚子 3 下的点击兜底。

### 7.7 音频

- Web Audio API 合成，无音频文件。
- 首次点封面时解锁 `AudioContext`；封面就是“开始”按钮。
- 音色：
  - `gulu`：90 Hz 正弦 + 6 Hz 颤音，0.6 s。
  - `chomp`：0.06 s 噪声 + 120→80 Hz 正弦，0.15 s。
  - `burp`：110→70 Hz 锯齿 + 500→150 Hz 短滑音（“啵”），0.45 s。
  - `snore`：低通噪声 + 60 Hz 正弦，1.8 s。
  - `pop`：600→200 Hz 正弦，0.1 s。
- 主音量 0.25；静音按钮 + `M` 键；不持久化。
- `prefers-reduced-motion` 不影响声音；静音是独立开关。

### 7.8 彩纸

- 每个爆发页由构建脚本用固定种子生成 96 个形状（圆/方/星/波浪/花），颜色从色板取。
- 形状的最终位置在构建时写死；屏幕动画从嘴巴位置飞到最终位置，1.2 s。
- 印刷时关闭动画，保留最终构图；屏幕/印刷共用同一批形状。
- `prefers-reduced-motion` 时直接显示最终构图。
- 不用 canvas；SVG + CSS transform，便于截图和印刷。

### 7.9 无障碍

- 每页 `aria-label` 是完整朗读文本；画面 `aria-hidden`。
- 页面切换后焦点移到页面容器；隐藏的 live region 播报当前页文字。
- 键盘：←/→、空格、回车、Home/End、M 静音、F 全屏、? 帮助。
- `prefers-reduced-motion`：翻页瞬时、彩纸不动、螺旋不转。
- 对比度：正文 ≥ 4.5:1；大字 ≥ 3:1；黄底用黑字。
- 不闪烁；无自动播放声音；封面点击后才发声。
- PDF 设置 `lang="zh-CN"`、`tagged: true`。

### 7.10 屏幕布局

- `body` 白底；`.stage` 居中，`width/height: var(--page)`。
- 页面绝对定位叠放；只显示 `.is-active`；`overflow: hidden`。
- 无滚动条；手机竖屏上下留白，舞台仍然 1:1。
- 字号/间距全部基于 `--u`，随舞台缩放。
- 只有两个常驻 UI：右上角静音按钮、帮助按钮；3 秒后淡出，点击页面再出现。印刷时隐藏。
- 构建产物是单个 `index.html`；桌面双击可读。iPad 建议用本地静态服务器或私有站点，避免 `file://` 的音频/字体限制。

## 8. 印刷导出

### 8.1 规格

| 项 | 值 |
|---|---|
| PDF 页面 | 216 × 216 mm |
| 成品 | 210 × 210 mm |
| 出血 | 3 mm 四边 |
| 安全区 | 成品内缩 8 mm |
| 页数 | 36（含封面） |
| 内文纸 | 200 g 哑粉纸 |
| 封面 | 300 g 哑粉 + 哑膜 |
| 装订 | 骑马钉；可选圆角（推荐 3 岁用） |
| 印法 | **双面**；页数必须是 4 的倍数（36 页 = 18 张纸对折成 9 帖） |
| 订口 | 折线在奇数页左边、偶数页右边；内容安全区内缩 8 mm，跨过折线的笔触允许 |
| 色彩 | sRGB PDF；印厂转 CMYK，必须打样 |

### 8.2 导出流程

1. `npm run build` 生成 `dist/print.html`。
2. `node tools/pdf.mjs`：
   - Playwright Chromium 打开 `print.html`。
   - `await document.fonts.ready`；等待无网络请求。
   - `page.pdf({ width: '216mm', height: '216mm', printBackground: true, preferCSSPageSize: true, margin: 0, tagged: true })`。
   - 输出 `dist/book.pdf`。
3. `python tools/check-print.py`：
   - 页数 36；页面 216 × 216 mm（612.28 pt）。
   - 字体全部嵌入；无 Type3。
   - 每页四角出血颜色符合预期（按页面背景表）。
   - 300 dpi 渲染到 `dist/proof/`。
4. `node tools/check-layout.mjs`：
   - 在 216 mm 宽度下量所有文字元素，必须在 11 mm 内边距内。
   - 文字容器无溢出（`scrollHeight <= clientHeight`）。
   - 屏幕 UI 在 print 媒体下 `display: none`。
5. 人工检查 4 个关键页的 300 dpi 渲染：封面、红页、彩虹页、夜页。
6. 印厂打样；确认 CMYK 色偏、黑字是否够黑、线条是否够粗。

### 8.3 裁切线

- 默认交付 216 × 216 mm 出血 PDF；印厂按出血裁切。
- 如印厂要求裁切线，用 `pdf-lib` 生成 226 × 226 mm 版本，在成品框外画角线；不改变内文 PDF。

### 8.4 色彩

- 屏幕用 sRGB 色板；印刷前提供 `palette.csv`（RGB + CMYK 近似值）。
- 荧光黄/红在 CMYK 里会变暗；先打样，必要时把 `--yellow` 调到 `#FFD400`、`--red` 调到 `#E23B2E`。
- 封面可用 Pantone 803C（黄）/ 485C（红）提亮；内文用 CMYK。
- 黑色：文字 100K；线条可用 100K + 30C 富黑，需印厂确认。

## 9. 构建与检查

### 9.1 构建

`tools/build.mjs`：

1. 读 `src/content/book.json` 与 `src/content/pages/*.html`。
2. 把 `components/*.svg` 的 `<symbol>` 注入隐藏 defs。
3. 生成 `dist/index.html`（屏幕）与 `dist/print.html`（印刷）。
4. 为爆发页注入固定种子的彩纸形状。
5. 把字体子集、CSS、JS 内联进 `dist/index.html` 与 `dist/print.html`；JS 按顺序拼成经典脚本。
6. 跑 `check-pages`、`check-layout`、`check-text`；任一失败即退出非零。

### 9.2 检查项

| 检查 | 工具 | 失败条件 |
|---|---|---|
| 页数/页面结构 | `check-pages.mjs` | 印刷 ≠36 页；页数不是 4 的倍数；每页 h1/hotspot 不符；ID 重复；符号缺失 |
| 文字安全区/溢出 | `check-layout.mjs` | 任一文字越界或溢出 |
| 字体覆盖 | `check-text.py` | 任一渲染字符不在子集 |
| 外链 | `build.mjs` | 出现 `http://`、`https://`、`//` 资源 |
| PDF 规格 | `check-print.py` | 页数/尺寸/字体/出血不符 |
| 视觉 | `shots.mjs` + 联系表 | 人工 2× 检查线条、字距、构图 |
| 交互 | Playwright 冒烟 | 封面→p5；点苹果→p8；点月亮→p24；静音；减少动效 |

### 9.3 视觉验证

- 每页截图 1440 × 1440（`?static=1`，关闭动画）。
- 生成联系表（4 列），每页缩放 330 px；先看整体节奏。
- 关键页 2× 放大检查：封面、红页、彩虹页、夜页。
- 与原书并排对比“气质”，不做像素对比（版权）。
- 线条必须看得出是手绘；出现完美圆/完美直线就重画。

### 13.1 名称与商标查重记录（2026-10-31）

按证据强度分三层。**只有第 3 层（中国官方库）能对"能不能用"下结论，前两层只能降低担忧。**

| 层 | 数据源 | 结果 | 能证明什么 / 不能证明什么 |
|---|---|---|---|
| 1. 网页 | 搜索引擎、书店目录、电商、应用商店 | 全网无同名绘本 / 品牌 / App / 游戏 | 没有「已经火到不用搜」级别的撞名；查不到 ≠ 不存在 |
| 2. 国际商标库 | WIPO Global Brand Database（85 个知识产权局、77,158,090 条，2026-10-30 数据） | 精确短语检索：**「啊呜噜啵」0 条、「噜啵」0 条、「啊呜」0 条、「AWULUBO」0 条**。对照组「LABUBU」319 条（泡泡玛特 class 28 等）→ 检索本身有效 | 欧美日韩印澳加英等 **85 个局**未被占用。**GBD 收录清单里没有 CNIPA，中国国内注册查不到，这层结论不覆盖中国** |
| 3. 中国官方库 | 商标网 `wcjs` / `pub` / `toas` / `tzwh` | 本机 IP `58.38.113.254`（阿里云机房段）被盾墙拦截，四个数据域全部 403，拦截页写明「抱歉，您的请求被阻断了 / Your IP 58.38.113.254」 | **无法从这里完成**。需在住宅网络人工查 9/16/28/41 类，或委托代理机构 |

另两条实打实的在先使用线索：

- **「啊呜」已经是出版书名**：《啊呜》（萧袤/唐筠，浙江少年儿童出版社 2013，ISBN 9787534277894，44 页）；另有《啊呜一口，吃掉烦恼》（人民邮电出版社 2023）、《啊呜啊呜大面包》（海洋出版社 2009）。书名不是商标，但 16/41 类的在先使用证据是实的——正式查重时以「啊呜」二字单列查一遍。
- **「噜啵」与泡泡玛特 Labubu（拉布布）音近义同**（都是给孩子的小怪物）。LABUBU 在 GBD 有 319 条全球注册、泡泡玛特持 class 28。整书名「啊呜噜啵」四音节 vs la-bu-bu 三音节、字形全不同，**不构成近似**；形象也刻意避开（无尖耳、无尖牙，只有肚子上的螺旋）。风险点在于**若「噜啵」被单独当作商品名称/商标用在玩具上**，届时须另做判断。

**结论**：作为**整体**书名，「啊呜噜啵」在全球范围未见占用，可以用；中国国内能否注册**尚未知**，出版/上架前必须人工查一次商标网。备选「啊呜噜咕」保留在案。
